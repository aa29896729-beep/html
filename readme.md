# 천만관객 한국영화 흥행 기록 수집 및 분석 앱

위키백과 '대한민국의 영화 흥행 기록' 문서에서 표 데이터를 수집하고 정제한 뒤, 지표와 표, 차트로 시각화하고 CSV 파일로 내려받을 수 있는 Streamlit 웹 앱입니다.

## 주요 기능

- 위키백과 주소 입력 및 버튼 클릭으로 HTML 수집 (`User-Agent` 및 `timeout` 적용)
- `class="wikitable"` 표 중 첫 줄에 `'관객수'`와 `'감독'`이 모두 포함된 첫 번째 표 탐색
- 각주 태그(`<sup>`) 제거 및 표 데이터(`<tr>`, `<th>`, `<td>`)의 `pandas.DataFrame` 변환
- 제목의 `《》` 기호 제거, 관객수 숫자 변환, 개봉일에서 `개봉연도`와 `개봉월` 추출
- 천만영화수, 역대 1위, 1위 관객수 지표 및 정제된 표 출력
- 정제된 데이터 CSV 파일 다운로드 (`utf-8-sig` 인코딩)
- 관객수 상위 10편 가로 막대차트와 개봉연도별 편수 막대차트 출력
- 네트워크 연결 실패, 시간 초과, HTTP 오류, 대상 표 미발견에 대한 예외 처리
